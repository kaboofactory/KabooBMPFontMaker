# KabooBMPFontMaker Output Format Specification

This document describes the output file formats (XML and FNT) generated by KabooBMPFontMaker.
Designed for AI context understanding.

## 1. XML Format (.xml)

Standard Bitmap Font XML format.

### Schema Structure

```xml
<font>
  <info /> <!-- Currently empty, preserved for compatibility -->
  <common
    lineHeight="[int: Pixel height of one line]"
    base="[int: Baseline position from top]"
    scaleW="[int: Texture width]"
    scaleH="[int: Texture height]"
    pages="[int: Number of texture pages]"
  />
  <pages>
    <page id="[int: Page ID, starts at 0]" file="[string: Filename of the texture]" />
    ...
  </pages>
  <chars count="[int: Total character count]">
    <char
      id="[int: Unicode character code]"
      x="[int: X position on texture]"
      y="[int: Y position on texture]"
      width="[int: Character width on texture]"
      height="[int: Character height on texture]"
      xoffset="[int: Drawing X offset]"
      yoffset="[int: Drawing Y offset]"
      xadvance="[int: X advance value (cursor move distance)]"
      page="[int: Page ID where this character is located]"
      chnl="15" <!-- Fixed channel value -->
      
      <!-- Optional Extended Attributes (if Data.XMLEx is true) -->
      u1="[double: UV coordinate left (0.0-1.0)]"
      v1="[double: UV coordinate top (0.0-1.0)]"
      u2="[double: UV coordinate right (0.0-1.0)]"
      v2="[double: UV coordinate bottom (0.0-1.0)]"
      count="[int: Index in generation sequence]"
      c="[string: The character itself]"
    />
    ...
  </chars>
</font>
```

## 2. Text Format (.fnt)

BMFont-compatible Text Format.
Keys and values correspond exactly to the XML attributes described above.

### Line Structure

1.  **info**
    *   Currently just the string `info` with no properties.
2.  **common**
    *   Format: `common lineHeight=[int] base=[int] scaleW=[int] scaleH=[int] pages=[int]`
3.  **page**
    *   Format: `page id=[int] file="[string]"`
    *   Repeated for each page.
4.  **chars**
    *   Format: `chars count=[int]`
5.  **char**
    *   Format: `char id=[int] x=[int] y=[int] width=[int] height=[int] xoffset=[int] yoffset=[int] xadvance=[int] page=[int] chnl=15`
    *   Repeated for each character.
    *   *Note: Extended attributes (u1, v1, etc.) are NOT explicitly output in the standard text format generation loop in current code, but XML always has the logic block. (Check CreateBMPFont.cs lines 790-798 for XML specific extensions. Text format generation at line 762/773/etc doesn't seem to include the extended 'if' block).*

## key Definitions

| Key | Type | Description |
| :--- | :--- | :--- |
| **lineHeight** | Int | The height of a line in pixels. Used for vertical spacing between lines. |
| **base** | Int | The distance from the top of the line height to the baseline. |
| **scaleW/H** | Int | Dimensions of the generated texture image. |
| **id** | Int | (Page) Page index. (Char) Unicode ID of the character. |
| **file** | String | Filename of the texture image for a specific page. |
| **x, y** | Int | Position of the character on the texture. |
| **width, height** | Int | Dimensions of the character on the texture. |
| **xoffset** | Int | How much to offset the character horizontally when drawing. |
| **yoffset** | Int | How much to offset the character vertically from the top of the line height. |
| **xadvance** | Int | How many pixels to move the cursor after drawing this character. |
